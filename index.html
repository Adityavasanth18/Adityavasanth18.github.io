LLM Internal-State Consistency

Python · PyTorch · Hugging Face Transformers · Gemma 3

Can a model’s internal state disagree with its own context, and can we tell that apart from activation size alone?

  • Developed a causal activation-patching research framework using Python, PyTorch, and Hugging Face Transformers, incorporating residual-stream interventions, donor-recipient activation swapping, forward-hook integration preparation, and first-token logit analysis to investigate context-dependent internal inconsistencies.
  • Conducted preliminary CPU-based experiments across 50 random seeds and 100 synthetic scenario families per run, evaluating conditional incompatibility using ridge regression, covariance-aware typicality estimates, nonlinear geometric controls, leakage-free cross-fitting, and block-level confidence intervals.
  • Validated the experimental pipeline with 170 passing tests and 20/20 mutation checks, investigating whether contextual incompatibility can be distinguished from activation magnitude and geometric confounders; prepared the Gemma 3 27B-IT protocol for subsequent pretrained-model GPU experiments.

Evaluation Context Invariance (ECI)

Python · PyTorch · Hugging Face Transformers · LLM evaluation

Do language models behave differently when they can tell they are being tested?

  • Designed and executed a preregistered 2×2 factorial experiment spanning 105 semantically matched scenario families, five domains, and two open-weight LLMs to isolate evaluation-awareness cues from deployment-style presentation.
  • Built a reproducible evaluation and statistical analysis pipeline measuring behavioral sensitivity to evaluation context, identifying a 2.4-percentage-point average cue effect, domain-dependent variation, and a context-sensitive model-ranking reversal.
  • Analyzed internal model representations using frozen linear activation probes (0.82 held-out AUROC) and causal activation steering with placebo and positive controls to investigate how evaluation-context information is encoded and influences model behavior.
